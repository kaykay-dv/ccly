# ccly

ccly (Cicely) is a portable Django project. The project lives in this package. A site is a directory with a `.env` file. Apps are separate packages created with `ccly create` and loaded by name.

Admin is served at `/m/`. The package includes Django REST framework, an OpenAPI document, django-axes, and django-ratelimit.
